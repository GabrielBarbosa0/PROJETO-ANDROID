# Projeto Android

![Preview do Bugdroid](image/bugdroid.png)

Este repositório guarda uma página simples sobre a história do mascote do Android, o **Bugdroid**. O projeto foi desenvolvido durante meus estudos de **HTML5 e CSS3** no Curso em Vídeo, do professor Gustavo Guanabara, e publicado no GitHub Pages como um dos meus primeiros contatos reais com desenvolvimento web.

> Mais do que um exercício, este projeto tem valor sentimental: foi um dos primeiros projetos que coloquei no ar enquanto ainda estava aprendendo os fundamentos da web.

## Acesse o projeto

[Ver página publicada no GitHub Pages](https://gabrielbarbosa0.github.io/PROJETO-ANDROID/)

## Sobre o projeto

A página apresenta uma breve história do mascote do Android, passando pela primeira tentativa de criação feita por **Dan Morrill** e pela versão final do Bugdroid criada por **Irina Blok**.

O conteúdo foi construído como uma página estática, com foco em praticar conceitos básicos de HTML e CSS:

- Estrutura semântica com `header`, `nav`, `main`, `article`, `aside` e `footer`;
- Imagens responsivas com a tag `picture`;
- Uso de fontes externas e fonte personalizada;
- Incorporação de vídeo do YouTube;
- Estilização com variáveis CSS;
- Layout simples e responsivo.

## Tecnologias usadas

- HTML5
- CSS3
- GitHub Pages

## Observação

Este projeto foi mantido com sua essência original. Ele representa uma fase inicial de aprendizado, com escolhas visuais e técnicas próprias daquele momento. Por isso, o objetivo aqui não é apresentar um projeto perfeito, mas preservar um registro importante da minha trajetória como desenvolvedor.
